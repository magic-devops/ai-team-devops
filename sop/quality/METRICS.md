# 质量指标体系

## 代码质量指标

| 指标 | 目标值 | 警戒值 | 测量方式 |
|------|--------|--------|---------|
| 测试覆盖率（行） | ≥80% | <70% | coverage report |
| 测试覆盖率（分支） | ≥70% | <60% | coverage report |
| 构建时间 | <2min | >5min | CI 日志 |
| 测试执行时间 | <5min | >10min | CI 日志 |
| 代码重复率 | <5% | >10% | jscpd/pylint |
| 圈复杂度（函数） | ≤10 | >15 | eslint/pylint |
| 函数长度 | ≤50行 | >100行 | linter |

## AI 输出质量指标

| 指标 | 定义 | 目标值 |
|------|------|--------|
| 首次通过率 | 代码无需修改直接通过审查的比例 | ≥70% |
| 任务完成率 | 任务按预期完成（无阻塞）的比例 | ≥85% |
| 估算准确率 | 实际时间在估算 2x 以内的比例 | ≥75% |
| 安全问题率 | 审查中发现安全问题的任务比例 | <5% |
| 回滚率 | 需要回滚的提交比例 | <3% |

## 迭代健康度指标

```
Sprint 健康度 = 完成任务数 / 计划任务数 × 100%

健康：≥80%
警戒：60-79%
危险：<60%
```

## 记忆系统健康度

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 记忆命中率 | ≥60% | 检索到的记忆实际有用的比例 |
| 状态一致性 | 100% | LanceDB 状态与实际代码状态一致 |
| 快照覆盖率 | 每 Sprint 至少 1 次 | 快照创建频率 |

## 质量门禁

### PR 合并门禁（必须全部通过）
- [ ] CI 构建通过
- [ ] 测试覆盖率 ≥80%
- [ ] 无 BLOCKER/MAJOR 级审查意见
- [ ] 无安全漏洞（依赖扫描通过）
- [ ] 代码格式检查通过

### Release 门禁（必须全部通过）
- [ ] 所有 PR 门禁通过
- [ ] 端到端测试通过
- [ ] 性能测试无回归（关键接口响应时间）
- [ ] CHANGELOG 已更新
- [ ] 版本号已更新
