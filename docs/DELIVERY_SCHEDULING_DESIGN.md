## 目标与数据归属

DeliveryWorkspace 是唯一规划数据存储，canonical Task 保持唯一主负责人、需求、迭代和业务状态。新 `member_calendars` 以稳定成员ID为键；`task_details.allocations` 保存显式每日资源预留段。不添加第二套任务或图，不保留旧 capacity=5、任务数量/容量负载及重复存储。MemberEdit 删除 capacity；资源 kind 创建后不可修改，避免隐式换单位。现有工具不作为 owner；预留可以登记协作人员、Agent和工具，但不代表真实连接或运行。

人类使用小时/日，步长0.5、0..24；Agent和工具使用整数槽位/日，0..100。单位由真实 kind 验证并由服务端存储，客户端不能改变。所有数量严格拒绝 bool、NaN、Infinity及错误步长。XS/S/M/L/XL仅是尺寸，绝不推算小时或槽位。

日历配置包含 `weekly` 七项（周一0至周日6，null未知、0明确不可用）和完整 `exceptions[{date,available,note}]`。日期例外覆盖周模板，可以为null表示当天未知。例外日期唯一，最多366项；读取完整配置，不因当前查询窗口丢失其他例外。未配置不补默认8小时/5槽位。可提供明确点击的表单预设，但需要用户核对保存。

预留输入 `[{member_id,starts_on,ends_on,quantity_per_day,weekdays}]`，最多80段/任务。日期含起止日，weekday使用0=周一..6=周日，非空且唯一；每日预留量必须>0，小时0.5..24、槽位整数1..100。服务端增加unit字段保存，旧段单位与当前kind不符时标为无效，不重新解释。每段需至少命中一天；同任务同资源只拒绝实际有效日期重叠，不误拒绝日期跨度重叠但工作日不同的段。

预留段必须落在完整任务日期范围内；无日期和单侧日期仍可表达，但不能挂预留。任务日期/预留调整按最终对象原子验证；不在后台自动平移、均分、填周末或重分配。新写只能使用当前真实活跃成员，失活或删除资源已有段保留清晰异常和ID，不自动绑定同名成员；用户须显式移除或重配。容量只作比较，修改日历不改变预留。

## 负荷与异常口径

每格分别给出活动负荷（所有未通过有效验收的显式预留）与全部预留。仅 verified_completed 释放活动负荷；raw completed、awaiting_review仍占用。全部预留是规划记录，不叫实际工时或实际并发。已结束而仍未验证的预留列为过期待交付，不自动移到今天。

日历available=null时利用率及超载量未知；available=0且活动负荷>0为不可用冲突，0/0为无预留/休息。存在负责人未登记预留、未排期等不完整信息时显示“已登记负荷 + 未登记任务”，不能绿色宣称余力充分。无allocation表示未登记，不能把未知需求当0。任务负责人可以只承担交付责任，不强制填工时，但明确标记其预留缺失。

小时与槽位按资源分组，不合成全队利用率；每日槽位跨日的合计若展示须称槽位·日。只计算当前项目预留与预算，不声称已扣除其他项目工作。筛选可收窄可见任务，但容量对比默认仍含当前项目全部占用，窗口内明确展示筛选外占用，不能用筛选隐藏超负荷。

资源预留也是任务计划字段：规范化allocations进入进度最小规划事实及不可变任务基线比较，预留变动可追踪而不作废验收。旧原始快照未采集该字段时为null未知，不能补造[]；当前明确无预留为[]。旧基线未知字段不当作已变化，比较通过incomplete_plan_fields明确不可比较；新基线两侧已知预留正常比较。日历可用量不是任务范围基线的一部分，不冒称已经冻结资源预算历史。

任务异常独立表达：未排期、单侧日期、日期错误、未归属/失活负责人、未登记负责人预留、失效资源、预留过期待交付、前置未验收、依赖日期冲突。已验证任务保留规划可查，不要求倒填历史工作量。字段不完整的现有任务不伪造数据；新编辑校验当前目标对象及受影响依赖。

## 版本与命令

新增 `planning_basis` 是完整项目当前规划内容指纹，绑定完整任务集合、canonical owner/status/有效验收、里程碑/迭代关联、日期、依赖、预留、当前资源身份和完整日历。不绑定查询窗口或界面筛选，不含 as_of。验收task_basis刻意不含日期，不能复用来防规划并发；两者分开。纯日期、日历和预留调整不改变验收依据，归属/内容/需求/验收关联/依赖继续遵守原永久失效。

- `member.calendar.save`：configure，payload `{member_id,planning_basis,weekly,exceptions}`。替换该成员完整配置；同一CAS/幂等/SQL事务。
- `tasks.schedule`：write，payload `{planning_basis,changes:[{task_id,starts_on?,ends_on?,allocations?}]}`，1..200条唯一任务。至少显式一个编辑字段，null日期清空，[]清预留，未给字段保持。按最终全部候选状态一次验证受影响入/出依赖与预留，再一次保存，失败不局部生效。
- 现有 `task.update` 保留合理的单任务计划入口，新增 allocations 与 planning_basis；涉及日期或预留时必须提供 planning_basis，调用相同最终规划校验模块。关联编辑仍要求task_basis。不能在单任务入口留下绕过段落边界或并发依据的分支。
- 新建task/tasks.plan的初始日期继续作最终图校验；不伪造预留。修改既有任务日期/预留只能通过上述统一校验。
- 新增结构化409 `planning_basis_changed`；项目版本或事务CAS冲突同样返回409。失败保留全部草稿，读取最新完整规划后明确采用；第二次读取失败不能继续采用旧候选。已删除任务不可采用，草稿可查看/复制/取消。

## 读取与预览契约

`GET /api/v1/delivery/schedule?starts_on=YYYY-MM-DD&ends_on=YYYY-MM-DD`：明确当前项目、纯读取、不初始化默认记录、不调用模型或运行。默认UTC今天至未来13天，最多92个含首尾日期；日期值按civil date使用，不把本地日期经UTC转换偏移。

响应提供 `project_id/version/planning_basis/as_of/timezone/range/permissions`、完整周模板与日期例外、窗口内资源日格及其贡献、紧凑当前任务规划、milestones/sprints筛选数据及异常计数。完整项目planning_basis与全项目占用不受前端成员/里程碑/迭代/异常过滤器影响。后端锁定实际typed shape后直接通知UI和root，避免未定义字段或重复派生业务规则。

资源格至少提供 date、available、active_load、total_reserved、overload（未知null）、unavailable、未登记数量/不完整标识及显式任务贡献。任务行至少包含ID/标题/req_id/需求标题、真实负责人/活跃状态、业务及有效交付状态、milestone/sprint、日期、前置及实际阻塞、完整预留、异常codes。失效/移除资源可单列，不能混入可用资源总量。前置在筛选外时仍可从当前项目原图定位；已删除前置明确显示缺失。

`POST /api/v1/delivery/schedule-preview`：与tasks.schedule相同payload，纯读取当前项目、校验planning_basis/最终图与预留，返回归一化每条before/after和具体变化/影响；不写receipt/事件/观测/任务、不改变资源负荷，不产生派发或模型请求。失败保持输入；预览通过不等于已保存，提交仍重新核验最新basis/CAS。

SDK `delivery_schedule(starts_on=None,ends_on=None)` 与 `delivery_schedule_preview(body)`；CLI `sop delivery schedule --from --to --json`、`sop delivery schedule-preview --file JSON`。写入使用固定Command原文件，重试保留身份。OpenAPI同步真实模型及输入条件，不保留删除的capacity字段。

## 四个关键界面与交互

1. 团队“成员/容量日历”：成员卡展示真实身份、单位和配置情况；日历按人/Agent/工具分组，日期格显示已登记活动负荷/可用量与异常。点击格打开当日任务、筛选外占用和未登记信息，容量配置完整周模板+日期例外，成功前不关闭。
2. 里程碑“里程碑/依赖排期”：真实任务条使用语义日期栅格，SVG辅助前置连线；条是键盘按钮，前置列表提供等价交互。未排期/单侧日期单列；过滤器外前置与缺失前置分别说明，不画假条。当前项目标题/目标与现工作台保持一致。
3. 排期与资源预留编辑：任务日期、每资源预留段的数量/工作日/日期及单位可见；不让工具进入owner选择。复用固定快照/草稿、CAS和明确采用。批量改期只修改用户选中任务，显式预览日期及预留前后值；若提供自然日平移，预留必须显式一起移动且预览工作日数量变化，不静默扩大范围。
4. 390px与异常状态：成员→日期→任务列表和依赖列表替代压缩甘特。筛选换行，日期前后切换、加载/空态/失败/权限不足/未知/0/失效与超载可读，焦点与键盘路径完整，三语和现主题tokens一致。

日期/成员/里程碑/迭代/异常/二级模式写URL；任务打开后保留背景筛选，返回与刷新恢复。实际服务、桌面/390px、键盘、三语核验；不以SSR或源码检查冒充真实渲染。
