# 项目创建、恢复与团队接续

`T-project-creation-workflow`，2026-10-28。基点 `39c16ecb429909cbe54a73aff0a1a727f26297c4`。本阶段为源码实现、运行待验；未执行测试、收集、类型检查、构建、浏览器、服务、SDK 或外部调用。

## 创建与准确确认

POST `/api/v1/projects` 必须携带调用方预先保存的 `idempotency_key`（8–128 位字母、数字或 `_.:-`）。初态默认 `planning`，可明确选择 `active` 或 `paused`。名称必填，业务线、描述、目录可稍后配置；不要求用户先配置向量库或开发工具。

服务端从操作类型、当前租户、创建者和原键生成独立命名空间的回执身份及确定性项目主键。规范化完整创建内容摘要固定于现有 `DeliveryReceipt`，版本为创建时点 0，不冒充项目后续版本。项目、创建者管理员成员身份和回执在同一 SQL 事务中提交。重放相同请求返回原项目身份；修改原键下内容返回 409。并发由主键唯一约束围栏，冲突回滚后只接受精确原回执。无新表或自动迁移。

权限仍由服务端核实，回执恢复要求当前有效创建权限及项目可访问。已创建项目后续改名、调整状态或业务线不影响原回执。原业务线已不存在时，已有回执仍先恢复；无回执时必须检查业务线归属。可选创建通知只在首次提交后尝试，不决定创建成功，也不保证跨进程崩溃下的通知送达。

原 SDK `create_project(body)` 透传此正式合同：调用方须先持久保存完整 body 和 key，未知结果使用相同 body/key 重试，不由 SDK 每次自动生成键。不提供无键重复创建的兼容分支。项目克隆是独立接口，不在此变更内。

## 浏览器草稿与请求恢复

组合页使用稳定租户及账号身份保存一个创建草稿；不保存令牌、登录修订或当前项目身份，不随工作区选择混入其他账号。每次编辑保存到本浏览器 `localStorage`。关闭后可从组合页恢复，浏览器刷新/重新打开后读取相同原件，不自动发请求。

编辑器持有原生 Web Lock；相同账号的另一编辑窗口只显示占用提示。关闭编辑器即释放锁，重开可重新取得。每次保存再次比较原始字节，检测外部修改后停止覆盖。损坏、跨身份、过大记录保留原件并停止提交。存储失败保留当前输入，允许重试；未保存的输入有离开保护，强制退出或浏览器清理仍可能丢失尚未保存部分。跨设备同步、浏览器不支持 Web Lock 的替代写入不在本阶段内。

同账号切换工作区、令牌或路由时，未保存输入留在同一内存记录中，旧操作回调失效；重新取得编辑权先等待本窗口的旧锁真正释放。持久记录里的草稿必须与固定原请求的规范化字段一致，否则保留原件并停止使用，避免界面展示与实际重放内容不一致。

状态为填写、发送、结果未知、明确拒绝、已确认。发送前固定并持久保存完整请求及键；同帧重复点击不再发送。刷新恢复发送中记录为未知，仅允许确认原操作。未知后的 403/409/422 不证明原操作未提交，仍保持未知。首发明确拒绝后，用户可显式修改保留草稿；成功回执保留至用户明确选择下一步。成功回执本地保存失败仍在当前页面保留已确认状态，重启则凭原请求恢复。

恢复入口位于组合读取失败和权限提示之外，不因查询失败被隐藏。当前读取错误、读取中或权限不可用不能授权新创建；恢复仍由当前服务端权限决定。账号、工作区、路由或编辑生命周期变化后旧请求回调不更新当前页面。

## 操作与布局

创建弹窗按名称、描述、业务线/初态、可选目录排列。描述使用多行输入，字段有长度限制、明确标签；业务线支持名称搜索，失败不继续使用缓存作为选择依据。主动作按当前阶段切换，关闭明确保留，丢弃草稿需要确认且不能撤销已创建项目。

成功后提供查看项目、配置人员、录入和拆解需求三条明确接续。跳转携带精确项目 ID；不自动切换工作区，需求入口继续经过已有项目上下文确认。项目人员入口仍是同一正式成员管理器，团队页继续管理人、智能体和工具身份。

成员管理新增姓名/邮箱/ID搜索，搜索或项目变化后回到分页首页；移除先展示成员和项目的明确确认，并说明对任务/验收证明的影响和不会自动转交任务。读取失败提供重读入口，无候选人员时说明下一步。成员写入仍为原人员 API，耐久原版本/原请求协议及变更影响预览尚未补齐，不能将其网络超时称作确定失败。
