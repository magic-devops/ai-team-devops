1. 平台定位

Hermes 是让 AI 真正能读懂、能执行、能回写、能持续优化的软件研发与数据智能操作系统。

AI Native SDLC
人 输入想法、业务目标、优先级和团队约束，负责判断、组织、授权与验收。
AI 理解需求、读取规约、拆解 DAG、选择工具、执行任务、生成证据和建议。
CLI/Agent 通过 Agent Feed 获取任务包，在项目仓库自主开发、测试、部署和回写结果。
平台 统一需求、调度、质量、知识、数据、运维、安全、审计和商业化治理。

所有接口、任务、知识、记忆、数据、事件和审计都必须由服务端解析并强制注入统一作用域。

Security Baseline

4. 核心能力地图

围绕 AI 可理解、可执行、可评估、可运营，补齐研发运维与数据智能全链路能力。

Capability Map

REQ需求与项目治理

支持多入口需求采集、需求评审、相似需求检测、验收标准生成、项目模板和团队权限。

  • Idea → Requirement → Epic → Task 全链路。
  • 需求自动补全背景、约束、风险和验收口径。
  • 项目初始化自动生成规约、知识库、Agent 接入包。

DAG任务调度中心

把需求拆成 AI 可消费任务包，生成优先级、依赖、阻塞原因和质量卡点。

  • DAG 依赖、批次计算、环检测、事件唤醒。
  • Agent Feed 输出命令、上下文、验收证据要求。
  • Agent Report 回写状态、分支、产物和 gate 结果。

AI智能控制与 AgentOps

统一 LLM、Skill、MCP、A2A、记忆、知识、评估和工具权限，避免能力碎片化。

  • 模型路由、成本治理、Prompt 评估和质量反思。
  • Agent 注册、能力发现、心跳、沙箱和审计。
  • 知识图谱与项目记忆辅助 AI 理解长期上下文。

OPS部署运维与 AIOps

将发布、监控、告警、诊断、自愈和复盘都任务化、流程化、可审计。

  • WorkflowOps 接入审批、发布、回滚和 Runbook。
  • 告警自动归因，生成修复 DAG 和 Agent 任务。
  • SLO、成本、性能、稳定性统一观测。

DATA数据智能平台

覆盖数据接入、开发、质量、指标、标签、问数、报表、归因和数据知产治理。

  • CDC、批流一体、Lakehouse、数据服务和语义层。
  • 质量规则、血缘、异常归因、告警转任务。
  • 多模态数据开发、标签画像和智能决策。

GRC安全、审计与商业化

企业级交付需要权限、审批、合规、用量、账单和插件生态的完整治理。

  • SSO、ABAC、字段级权限、敏感数据策略。
  • Audit Chain、WORM、操作证据和审批追踪。
  • 租户配额、模型用量、插件订阅和企业账单。

5. AI 自主开发闭环

平台目标是让 AI CLI 能从项目任务池自动取活、开发、测试、部署、回写证据，并持续接收数据洞察驱动的新任务。

Agent Loop
需求输入人输入想法、目标、范围、负责人和优先级。
智能拆解AI 生成验收标准、任务、依赖和风险。
DAG 调度计算可执行批次、阻塞原因和质量卡点。
Agent 取活CLI/Agent 拉取任务包、规约、知识和命令。
自主开发Agent 在仓库内编码、测试、生成产物。
质量回写回写状态、证据、分支、评估和阻塞项。
运维洞察发布、监控、归因、优化并生成下一轮任务。

6. 调度中心目标能力

调度中心不是简单定时器，而是面向 AI 自动执行的任务操作系统。

Scheduler OS
能力 目标设计 AI/CLI 使用方式
DAG 依赖 支持 blocks、relates、duplicates、环检测、批次计算、阻塞原因输出。 CLI 只领取 ready 任务，blocked 任务返回依赖链和等待事件。
调度策略 balanced、quality_first、throughput、cost_saver、ai_first、human_review。 Agent 根据策略选择模型、工具、并发、测试深度和人工确认点。
质量卡点 规约加载、需求追溯、实现说明、测试证据、视觉验证、安全扫描、运维观测。 Report 必须提交 gate_results，失败自动转 blocked 或生成修复任务。
事件唤醒 task.created、task.status_changed、agent_reported、notify.inbound、agent.heartbeat。 Agent 订阅或轮询 feed，平台可基于事件主动分派任务。
运行证据 artifact、branch、commit、log、report、screenshot、trace、deploy id。 AI 产物进入审计链和知识库，用于复盘、学习和二次调度。

7. 数据智能平台

数据能力是 Hermes 的第二主线，服务业务智能迭代、智能运营、智能决策和 AI 长期学习。

Data Intelligence

数据链路

从业务源、项目事件、Agent 证据、日志指标和外部系统接入，经过批流一体开发和质量治理，形成指标、标签、知识和任务。

  • 智能数据接入、Schema Registry、Flink CDC、离线/实时同步。
  • Spark/Flink/SQL/Python 数据开发和多模态数据处理。
  • 数据质量评估、血缘影响分析、监控告警、异常归因。

智能服务

指标中心、标签中心、画像服务、智能问数、智能报表、智能归因和统一数据服务对业务与 AI 同时开放。

  • 指标语义层、口径审批、血缘和服务化 API。
  • 标签开发、用户/企业/项目画像、本体论 AI 记忆。
  • NLQ、报告生成、经营洞察、告警转需求/任务。
技术 平台角色 采用策略
OceanBase主数据、HTAP、多模态、审计和统一数据服务底座。作为默认企业级主存储，承载租户、任务、权限、数据服务元数据。
StarRocks高并发 OLAP、指标服务、实时看板。承载指标中心查询加速和 BI/NLQ 低延迟分析。
Hologres / Greenplum实时数仓、MPP 离线数仓和复杂 SQL 分析。兼容云上实时分析和存量企业数仓迁移。
ElasticSearch / OpenSearch全文搜索、日志检索、告警分析、知识检索。服务统一搜索和可观测数据查询。
Spark / Flink / Paimon批流开发、CDC、Lakehouse、实时质量和实时标签。作为成熟数据开发与湖仓一体能力。
Lance / LanceDB向量、多模态资产、代码/文档检索和 Agent 记忆。支持本地优先 RAG、图文向量和轻量多模态索引。

10. 部署拓扑与工程保障

优先采用成熟技术，支持单机、团队、SaaS、企业私有化和混合云形态。

Enterprise Ready

部署形态

  • single：本地 SQLite/文件记忆/本地向量，适合个人和团队试用。
  • team：Manager API + Worker + Redis + OceanBase/MySQL，适合团队协作。
  • saas：多租户、SSO、配额、计费、审计、可观测和数据隔离。
  • enterprise：私有化、专有网络、WORM、密钥托管、离线模型和混合云数据。

工程保障

  • API 契约、SDK、CLI、前端页面与 Agent Feed 保持同步演进。
  • 所有高风险动作走审批、审计、策略引擎和回滚预案。
  • 任务、数据、模型、工具、插件、用量均可观测、可限流、可追踪。
  • 新功能通过模块 Manifest、SystemMap 和测试证据纳入治理。
