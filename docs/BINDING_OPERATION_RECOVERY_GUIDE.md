# 恢复运行关联保存

当前阶段仅完成源码和源码审查准备，实际测试与浏览器验收后置。

在团队详情保存或解除运行关联时，页面会先保留本次原请求，再发送保存。发送中请等待；界面不会通过重复点击另建操作。

出现“保存结果待确认”时，使用“恢复原请求”。恢复会重发同一动作、完整参数、原版本和原幂等键，不会换成最新配置。即使最新关联看起来符合预期，也应确认原回执。恢复时仍受服务端当前项目和账号权限约束。

获得匹配回执后，选择“应用回执并刷新”。如果刷新失败，确认回执继续保留，可再次应用；不会因此重复保存。旧回执只证明原操作曾经成功，页面会重新读取当前关联，不把旧配置覆盖回去。

原请求被明确拒绝时，可以丢弃该拒绝请求；原编辑窗口中也可读取最新关联，核对后明确采用新依据继续修改。结果未知时不提供丢弃或重新编辑入口。

关闭成员详情或刷新页面后，可从团队页“待处理的关联保存”重新打开。成员当前不可读或已不存在时仍可查看保留的操作并尝试恢复。损坏或无法读取的记录会阻止覆盖；保留当前浏览器会话并使用重新加载入口核对。

保存或恢复迟迟没有返回时，可在编辑窗口选择“保留操作，稍后恢复”。它只关闭当前编辑窗口，保留同一请求和恢复入口，不代表取消或失败，也不会再次提交。

恢复记录限定当前已授权浏览器标签页会话，按账号、租户、业务、项目和成员隔离。不要把退出登录、清除浏览器存储或新开标签页视为原操作已失败的证明。工具名称及关联有效仍不代表外部工具连接已验证。
