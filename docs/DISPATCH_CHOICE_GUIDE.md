# 选择执行资源并派发

对应 `T-dispatch-choice-experience`。本阶段按用户要求只完善源码，以下交互尚未运行、构建或浏览器验收。

在任务中打开“派发任务”，先核对当前任务要求和明确选中的返工反馈。资源列表把执行方式与成员合在一起：选中一个资源后，点击“继续”，无需再分别打开两个选择框。

平台智能体项显示当前成员关联的配置、固定版本和可选执行位置数；外部协作项显示登记的工具和当前可用状态。同一成员可以有不同的交付方式，应明确选中本次需要的方式。需要自行配置时选择“直接选择 Agent 配置”或“编排命令计划”，然后在原有编辑器完成配置。

可按成员名称、工具或工作区搜索。搜索不会派发、重新请求数据或改变当前选中项；即使所选资源暂时不在搜索结果中，“当前选择”仍会保留。列表默认显示 40 项，可显式查看更多。可用资源优先展示，不可用项保留具体原因及可展开的原因详情。

没有可运行的位置、配置版本已变化、成员不可用、任务条件未满足或外部工单仍活跃时，对应选项不可继续。先处理显示的原因，再重新读取当前能力；界面不会替你换成其他方式。资源“当前可选”只反映本次能力读取，实际执行仍须原有预览、授权与明确确认。

点击“继续”会重新读取来源和能力。发现变化时保留当前草稿，展示新事实；明确采用后重新选择。编辑期间若账号、路由、权限或其他草稿状态变化，旧回调和后到响应不能继续派发。未发送的窗口可以关闭；结果未知的命令仍按保存原件恢复。

本次没有新增自动执行平台，也没有改变 SDK、CLI 或服务端命令合同。外部工单的派发与可下载工作包仍不代表外部工具已启动或已完成认证。版本化工具配置、自动执行适配及完整研发全链路继续推进；实际测试和界面效果留待验证窗口恢复后核验。
