# 任务详情操作导航

任务详情顶部目录可直接定位到平台执行、外部工单、设计依据、交付验收、计划依赖与讨论。定位只改变阅读位置，不切换任务，也不会关闭草稿或移除原操作恢复入口。

“记录状态”表示任务记录；“有效交付状态”来自当前服务端业务事实。只有有效验收通过才显示“已按当前条件验收”。记录完成且尚未有效验收时，会提示核对证据。

“查看下一步处理区域”只帮助定位：原生执行的处理留在平台执行区；外部报告与人工审核在交付验收区；依赖阻塞在计划依赖区。是否可以派发、提交或验收，继续由对应区域和服务端核实。它不会自动启动工具、认领工单或提交验收。

没有明确事实时，不显示下一步建议。没有平台运行的任务可能由人处理，不能据此推断已有外部工单，可通过目录自行查看相应区域。

正在编辑或保留待恢复操作时，摘要会显示“固定任务快照”与“快照交付状态”，此时不提示当前验收完成或下一步处理。先处理草稿/原操作，再刷新核对当前事实。

无法读取当前任务时，目录仍保留外部工单、设计和交付验收等独立恢复区域；原件不可读时按该区域提示处理，不另建请求替代未知操作。恢复原请求仍受原账号、原项目和原会话权限约束。

当前为源码阶段，测试、类型检查、构建与真实浏览器验证均未执行。窄屏、焦点、滚动与长内容效果需在用户确认验证窗口恢复后核验。
