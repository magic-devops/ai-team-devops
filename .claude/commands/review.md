# /review - 代码审查

对当前变更执行全面代码审查。

## 执行步骤

1. 运行 `git diff HEAD` 获取变更内容
2. 对照 `sop/quality/CODE_REVIEW.md` 检查清单逐项检查
3. 检查安全漏洞（OWASP Top 10）
4. 检查性能问题（N+1、全量查询、缺少索引）
5. 输出结构化审查报告

## 输出格式

```
## 代码审查报告

### ✅ 通过项
- ...

### ⚠️ 建议改进
- [文件:行号] 问题描述 → 建议方案

### ❌ 必须修复（阻塞合并）
- [文件:行号] 问题描述 → 修复方案

### 置信度: X/10
```
